ClipSense 桌宠菜单 · Hover 方案对比

按钮皮肤、环形布局、飞散展开动画全部复刻自真实菜单，唯一变量是 hover 表现。把鼠标移到任意圆形按钮上，四套方案可同屏对比。

↑ 依次 hover 四个环里的同一个位置，对比「浮起幅度 / 描边 / 辉光 / 底色变化 / 节奏」

方案来源：A 对应主界面 .item:hover（上浮 + 深影）与紫色焦点环；B 对应 .pin-btn.pinned（品牌紫辉光 + 亮边）；C 对应 .header button:hover（透明度递进，最安静）。
