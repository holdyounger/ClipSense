# 绿幕素材视频的上游生成

主流程（SKILL.md）吃的是**绿幕 mp4**。本文档说明这段视频怎么来。AIGC 环节依赖外部视频生成服务与本地浏览器自动化，属**环境相关步骤**：仓库中只沉淀方法、提示词模板与操作要点，**不得写入任何服务 API Key、Token、账号登录态或机器特定凭据**；服务选择、账号、额度由使用方自行管理。

## 目标产物规格

| 项 | 要求 |
| --- | --- |
| 画幅 | 1:1（桌宠窗口近方形） |
| 分辨率 | 480×480（起步够用；边缘质量优先于分辨率） |
| 帧率 | 24fps |
| 时长 | 5s（待机动作循环） |
| 背景 | **纯净均匀纯绿**，无地面/地板/阴影/桌子/环境 |
| 角色 | 悬浮居中，全身入镜，固定正面机位，无镜头移动，无文字水印 |

## 绿幕提示词模板（图生视频）

参考图 = 已审核的角色定妆图（灰底或绿幕均可，需与动作一致的形象基准）。提示词骨架：

> 同一只 {角色描述}，保持参考图中的脸、毛发、{配饰}和比例完全一致。整个画面背景必须是纯净均匀的纯绿色绿幕，全程保持纯绿背景不变，不允许出现地面、地板、阴影、桌子或任何环境元素，角色悬浮在纯绿背景前。做{动作描述}。固定正面机位，全身入镜，无镜头移动，无文字水印，动作平滑。

动作描述示例（待机 d1）：

> 做自然待机动作：身体重心缓慢左右轻摆，头部轻轻转动，耳朵和尾巴有细微跟随，呼吸起伏自然，表情友好平静。

要点：
- 强调“**全程保持纯绿背景不变**”——防止生成中途背景漂移成其他颜色。
- 明确“**角色悬浮、无地面/阴影**”——防止出现地板/投影（这是抠像斑驳的首要污染源）。
- 参考图是形象一致性的锚点，动作提示词不要改角色外貌描述。

## 生成参数

- 模型档位：免费档（排队）或优先生成（付费/积分），按可用性选。
- 480p / 5s 起步验证；确认边缘质量后再考虑 720p。
- 一次动作一支视频；待机/点击/拖拽各自单独生成。

## CDP 驱动浏览器（可选加速）

若用户本地浏览器以远程调试端口（如 Chrome/Edge `--remote-debugging-port=9222`）开启，可通过 CDP 自动填写表单、上传参考图、触发下载，免去手工操作。要点：

1. 连接 `http://127.0.0.1:9222/json` 找到目标页的 `webSocketDebuggerUrl`。
2. 上传用 `DOM.setFileInputFiles` 指向本地参考图路径。
3. 触发下载用 `Browser.setDownloadBehavior` 指定落盘目录，再点产物下载链接。
4. 轮询任务状态（队列/渲染中/完成），完成后取下载链接。

**边界**：
- CDP 脚本若需入仓库，只保留**通用、无凭证**的命令（连端口、找页、上传、下载），不含登录态。
- 页面 DOM 结构可能随服务改版变化，选择器要可维护、失败要可诊断，不要硬编码脆弱路径。
- 排队/渲染耗时不可控，脚本须支持超时与幂等重试。

## 拿到 mp4 后

下载完成后，把 mp4 交给 SKILL.md 主流程（第 1 步抠像起）即可。
