桌宠透明 WebM 素材管线

把一支绿幕视频，变成可直接上线的透明桌宠素材：OpenCV 色键抠像 + 去绿 spill + 边缘羽化， VP9 alpha（yuva420p）编码，一键部署到 pet-moves，深色背景前实机验收。

本 Skill 已随仓库发布，WisCode 在 ClipSense 项目中按触发词自动加载。

01 · 绿幕素材

图生视频产出「纯绿背景、角色悬浮、无地面阴影」的 480×480 / 24fps / 5s 绿幕视频，参考图锁定形象一致性。

上游 AIGC 图生视频（绿幕提示词模板见 Skill）
02 · OpenCV 色键抠像

HSV 色键生成 alpha，去绿 spill 防白毛染绿，边缘羽化 + 1px 收缩，输出 RGBA 帧序列。

python scripts/pet_pipeline/greenscreen_matte.py 绿幕.mp4 frames
03 · VP9 alpha 编码

RGBA 帧序列编码为 VP9 yuva420p WebM，无音轨，透明通道由 <video> 原生渲染。

powershell -File scripts/pet_pipeline/encode_webm.ps1 -FramesDir frames -Output d1.webm
04 · 部署与验证

一键备份并替换桌宠项目 pet-moves 素材（src + dist），重启实机在深色背景前验收边缘透明。

powershell -File scripts/pet_pipeline/deploy_greenscreen.ps1 -RawMp4 绿幕.mp4 -Move d1
触发场景

“给桌宠生成透明 WebM”“绿幕视频抠成透明素材”“替换 pet-moves 的 d1/p1/t1 素材” “视频转 VP9 alpha WebM”等请求会自动触发本 Skill。

边界与安全

只覆盖“绿幕 mp4 → 透明 WebM → 部署”的确定性环节；AIGC 生成环节仅文档化流程与提示词模板。 仓库不含任何服务凭证、API Key 或机器私有路径；部署前自动时间戳备份原素材。
