# ClipSense v1.0.8 Release Note

发布日期：2026-09-30

本版本为**升级链路验证版**：验证「检查更新 → 下载 → 静默安装 → 自动启动新版本」全流程闭环，并带「检查更新超时守卫」一个小改进。无新功能。

## 🐛 问题修复

### 检查更新超时守卫
- 现象：GitHub API 限流（403）触发降级链时，链内串行请求（API + Atom + 网页 + 直链探测）
  在极端网络下最坏可累积数分钟，表现为菜单项「检查中…」久挂
- 修复：检查更新加 60s 总超时守卫（`Promise.race`），超时返回结构化错误
  「检查超时（60s），请检查网络后重试」——菜单项立即恢复可重试状态

## ⚠️ 已知事项 / 行为变化

- 本版本核心目的是验证 v1.0.7 引入的「NSIS customInstall 静默升级后自动启动」：
  从 v1.0.7 检查更新升级到本版本时，安装完成后**应自动启动 v1.0.8**（无需手动启动）。
  若未自动启动，请反馈现象（NSIS include 机制需实机确认）
- 升级链路无签名/哈希校验（同前版本）

## 📌 升级说明

- 无破坏性变更，历史数据与配置完全兼容
- 从 v1.0.7 检查更新升级即可；发布锚点：git tag `v1.0.8`（package.json version 已同步）
