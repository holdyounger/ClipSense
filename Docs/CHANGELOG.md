#### 贴边抽屉动画失效（根治）
- 症状：面板贴边收起后复制内容，贴边触发条的抽屉动画不再播放

  贴边补播）全部迁移到权威信号
- 取证方式：userData 落盘诊断日志（五站埋点），复现一次即锁定「数据源到达、gate 零放行」

#### 透明度三问题（固定模式 footer/backtop/计数重复）
- 固定模式 footer 不透明：`.footer` 背景消费 `--win-alpha`
- backtop 按钮透明适配：背景/border `calc(0.85|0.4 × --win-alpha)`，hover 同步
- footer 计数与 headerMeta 重复：移除 footer 统计行，计数唯一展示位收敛为 header 辅助行

- 新增三套测试：header-hover（50 条）+ wiring（含 G 组可见性迁移/I 组透明度覆盖收敛/

### ⚠️ 已知事项 / 行为变化

### ✨ 新特性

#### Header 可变高度（hover 自适应，方案 A）
- 静止态 32px / 悬停展开 60px（瞬切，无 height 过渡）；列表位移由 spring(240/22) FLIP

- 搜索展开 / 菜单打开时锁定展开态；拖拽结束 200ms 恢复缓冲；reduced-motion 瞬切降级
- 展开态辅助行：「共 N 条 · 上次复制时间」（中英文案）

#### 辅助行常驻行中置
- 「共 N 条 · 上次复制时间」移入 header 行中部**常驻显示**（绝对定位真居中，不再仅 hover 可见）
- 搜索展开时淡出让位（输入框占满行中部）；`pointer-events: none` 不挡交互；超长省略号截断

#### 按钮两态联动
- 右上三键（搜索/固定/菜单）随 header 两态缩放：静止 20×20（圆角 5）/ 悬停恢复 24×24（圆角 6）
- 图标与倒计时数字同步缩放；倒计时环 viewBox 自适应，进度语义不变

#### 窗口两段式透明度
- **固定模式开启** → 窗口整体透明度降为 **60%**（实机调参定案，初版 80%）
- **贴边倒计时**（鼠标离开）→ 从不透明随剩余时间**线性降至 40% 可透视档**，
  倒计时结束达到「不影响观察下方窗口内容」；鼠标重进立即恢复
- 实现为主进程推送 + 渲染层 CSS alpha（`--win-alpha` 变量）——支持**悬停条目恢复 100%**
  （半透明状态下悬停的条目以完全不透明绘制，保证可读性；详见架构说明）
- 透明度计算纯函数化（`computeOpacity`），常量集中可调

### 🐛 问题修复

#### 贴边抽屉动画失效（根治）
- 症状：面板贴边收起后复制内容，贴边触发条的抽屉动画不再播放
- 根因：v1.0.4 为修弹出闪烁引入 `backgroundThrottling: false`，其副作用是
  `document.visibilityState` 恒为 `'visible'`（窗口隐藏也不再变化）——贴边动画的
  gate 依赖 `visibilityState === 'hidden'` 判定贴边态，从此永不进入，动画播进了隐藏窗口
- 修复：可见性源迁移——主进程 `isWindowVisible` 为唯一权威（`setOnVisibilityChanged`
  回调 + `window:visibility` 频道），渲染层贴边 gate 与「重显动作」（筛选重置/搜索态
  恢复/贴边补播）全部迁移到权威信号
- 取证方式：userData 落盘诊断日志（五站埋点），复现一次即锁定「数据源到达、gate 零放行」

#### 贴边触发条位置漂移 / 逐周期缩小直至消失

- 根因：抽屉动画「临时扩窗 → 回缩」编排以**每次事件现抓的窗口 bounds** 作为回缩基准；

## v1.0.0（2026-08-28）— 首个公开版本

ClipSense 是一款基于 Electron 的剪贴板历史助手，支持自动记录剪贴板内容、历史搜索、指定条目粘贴以及窗口边缘唤出。

### ✨ 主要功能

- 📋 自动监听系统剪贴板，默认每 `600ms` 检查一次
- 🗂️ 支持文本、富文本、图片和文件历史记录
- 🔍 支持搜索剪贴板历史内容
- 📌 双击历史条目即可：
  1. 将指定条目写入系统剪贴板
  2. 向目标窗口发送一次 `Ctrl+V`
  3. 粘贴被选中的历史内容
- 🖼️ 支持图片历史持久化
- 📁 支持文件条目预览和 Windows Explorer 定位
- 🧾 空格、Tab、换行等空白内容可视化显示
- 🖱️ 支持窗口贴边、拖拽和边缘触发
- ⏱️ 支持鼠标离开后的自动隐藏倒计时
- 📌 支持固定窗口，防止自动隐藏
- 🔒 使用 Electron `safeStorage` 加密历史数据和图片
- 🎨 新增卡通风格应用 Logo 和托盘图标
- 🪟 支持 Windows 系统托盘运行
- ⚙️ 新增 GitHub Actions 自动构建和 Release workflow

### 🔐 数据与隐私

剪贴板历史保存在 Electron `userData` 目录中，主要包括：

```text
clipboard-history.json
clip-images/<id>.bin
clip-history-config.json
```

如果系统支持 `safeStorage`，历史元数据和图片会进行加密存储。若系统不支持安全存储，程序会降级为明文存储并输出警告。
