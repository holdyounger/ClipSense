# ClipSense v1.0.7 Release Note

发布日期：2026-09-30

本版本聚焦**标签系统通用化**（12 → 22 类，适配大众工作类型）与**静默升级后自动启动**（消除升级代际限制）。测试基线 521 → 530 条，全量绿。

## ✨ 新特性

### 标签系统通用化（12 → 22 类）
- 新增 10 类通用标签，适配大众工作类型（快递单号、银行卡、手机号、身份证、会议日程、待办、账号凭据、UUID、颜色值、地址）
- 全部强特征正则/结构化校验路线，误报率设计目标 <1%：
  - 银行卡：13-19 位提取 + Luhn 校验
  - 身份证：仅 18 位 + GB 11643 校验位算法 + 省份/日期粗校验（15 位旧号不启用，防误报）
  - 快递单号：SF/YT/JD/EMS/邮政前缀白名单 + 位数区间
  - 手机号：`1[3-9]` 开头 + 边界断言，容忍 `+86`/分隔符变体
  - 会议日程：日期词 + 显式时刻 + 会议动词三重共现
- TAG_PRIORITY 扩至 22 类价值序（凭据/资金类紧跟安全类）；`normalizeEnabled` 补 10 开关（默认全开，可逐类关闭）
- 筛选条零改动自动获得新标签；i18n 中英 20 key（44 个全齐备）
- 10 个识别器独立导出（测试/诊断用），性能预算 5→8ms（64KB 混合文本，PRD §六）

### 静默升级后自动启动（NSIS customInstall）
- 静默升级（`/S`）安装完成后**自动启动新版本**——消除「装完没反应」的代际限制
  （此前依赖新包自带的重启脚本，首次升级到带脚本版本前无法自动重启）
- 交互式安装不受影响（向导自带「运行应用」勾选）
- 写法对齐 electron-builder 官方 `${isUpdated}` 惯例（installUtil.nsh 同款）

### 升级流程反馈补全（v1.0.5 引入的重启机制的 balloon 文案优化）
- 发现新版本：「开始下载…（完成后将自动安装并重启）」
- 下载完成：「正在静默安装…完成后将自动重启」

## 🐛 问题修复

### meeting 标签误报（负例回归捕获）
- 现象：中文叙事文本「我们明天上午十点在 3 号楼**会议室**对齐上线方案」误命中会议标签
- 双层修正：
  1. 裸日期词（明天/周X/日期）单独不判，必须与显式时刻（`HH:MM` 或中文「X点」结构）共现
  2. 动词「会议」加负向断言 `会议(?!室)`——排除「会议室」场所词
- 既有正例（显式时刻 + 会议动词）全部保持命中

### 快递单号位数盲区
- 首版正则 `SF\d{15}` 不匹配真实单号的常见位数——放宽为前缀 + 位数区间
  （`SF\d{12,16}` 等），负例（纯长数字串）仍不误判

## 🧪 测试与工程

- TAG_PRIORITY 清单断言同步 22 类；meeting 正负例回归（neg-prose-zh 零误报 + 4 条正例保持）
- 性能预算断言同步：64KB 混合文本打标 5ms → **8ms**（22 类识别器，PRD §六 口径）
- 全量 **530 / 530 绿**（十二文件，0 fail / 0 todo）

## ⚠️ 已知事项 / 行为变化

- **性能预算口径变更**：64KB 打标从 <5ms 放宽至 <8ms（标签数翻倍的合理代价，实测 3.1-4.6ms）
- 设置面板的标签逐类开关 UI 尚未覆盖新 10 类（当前仅 `--win-alpha` 同源的配置通道，UI 跟进为可选优化）
- 升级链路无签名/哈希校验（同 v1.0.4-1.0.6）；下载不支持断点续传
- i18n 的 `statCount`/`statFiltered` 为孤儿 key（v1.0.5 移除底部统计行后遗留，无引用）

## 📌 升级说明

- **从 v1.0.6 升级到本版本后，后续升级将自动重启**（v1.0.6 已内置重启脚本，本版本为 NSIS 层双保险）
