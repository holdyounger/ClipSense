# ClipSense v1.0.1 Release Note

发布日期：2026-09-01

本版本聚焦**贴边交互体验的全面打磨**：重构边缘触发条、重写窗口滑入/滑出动画机制、修复多处快速操作与鼠标划过引发的竞态和闪烁问题。

## ✨ 新特性

### 边缘触发条重构
- 触发条窗口宽度优化为 `6px`，命中区域与可见条完全一致
- 触发条高度与主面板 header 对齐（实测 `.header` 高度，兼容 DPI 缩放），不再占满整个面板高度
- 支持左右两侧边缘触发区域检测

### 窗口滑入/滑出动画重写（CSS 合成器驱动）
- 弃用主进程逐帧 `setPosition`/`setOpacity` 原生动画，彻底解决 Windows 上贴边动画闪烁问题
- 新增 `slide-anim.js`：通过 CSS `transform` + `opacity` 过渡实现淡入淡出 + 轻微滑动，动画由合成器驱动，流畅不闪
- 主窗口透明化（`transparent: true` + `#00000000`），滑出时不再残留白色背景块，圆角外区域也真正透明
- 动画期间窗口设为透明底色（`#1e1e23`），消除无框窗口白底闪白

## 🐛 问题修复

### 交互稳定性
- **Ctrl+Shift+V 连按竞态**：toggle 加过渡锁，修复快速连按导致窗口跑到屏幕外的问题
- **鼠标快速划过不误隐藏**：mouseleave 加 120ms 防抖，渲染进程瞬时上报与主进程轮询竞争导致的倒计时徽章闪现已修复
- **倒计时未生效**：修复轮询每帧重置防抖定时器、倒计时永不触发的 bug
- **提示条（hint）快速划过**：改为停留 150ms 才展开，划过根本不弹出；展开态移出延迟 200ms 收起
- **倒计时徽章闪现**：hintEl 划过瞬间 leave→轮询纠偏之间的假信号不再触发徽章弹出

### 视觉
- **贴边触发条高度**：不再占满面板全高，仅与 header 一致
- **滑出白色残影**：主窗口透明化修复，退出动画不再残留白色矩形
- **动画期间底部滚动条**：`html, body` 增加 `overflow: hidden`，滑出动画平移不再弹出水平滚动条

## 🔧 内部改进

- `edge-detector.js` 大幅重构（+214/-89），新增防抖机制与动画状态管理
- 窗口 `_hiddenAtPos` 恢复时增加工作区校验，异常位置自动回退拖拽位置
- 隐藏后 400ms 内防抖抑制，光标未离开触发条不会立刻弹回
- 演示效果图替换为 GIF 动画，更直观展示运行效果

## 📦 升级方式

从 [Releases](../../releases) 下载最新的 Windows 安装包（NSIS），覆盖安装即可。

## ⚠️ 已知限制

- 滑动动画为窗口内淡入淡出+轻微位移（非真正滑出屏幕），受 BrowserWindow 系统裁剪限制
- 首次启动如未出现托盘图标，请检查系统托盘隐藏设置
