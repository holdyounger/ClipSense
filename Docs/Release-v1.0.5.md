# ClipSense v1.0.5 Release Note

发布日期：2026-09-30

本版本聚焦**顶部 header 栏可变高度（hover 自适应）**与**窗口两段式透明度**，并根治了贴边抽屉动画失效问题。测试基线 432 → 521 条，全量绿。

## ✨ 新特性

### Header 可变高度（hover 自适应，方案 A）
- 静止态 32px / 悬停展开 60px（瞬切，无 height 过渡）；列表位移由 spring(240/22) FLIP
  transform 补偿——性能红线（只动 transform/opacity）零豁免
- hover 判定走主进程 edge-detector 既有 100ms 轮询（drag 区吞 DOM 事件，纯 CSS :hover
  不可靠）；进入即时、离开防抖 180ms、面板唤出后 400ms 抑制（防「弹出即展开」抖动）
- 搜索展开 / 菜单打开时锁定展开态；拖拽结束 200ms 恢复缓冲；reduced-motion 瞬切降级
- 展开态辅助行：「共 N 条 · 上次复制时间」（中英文案）

### 辅助行常驻行中置
- 「共 N 条 · 上次复制时间」移入 header 行中部**常驻显示**（绝对定位真居中，不再仅 hover 可见）
- 搜索展开时淡出让位（输入框占满行中部）；`pointer-events: none` 不挡交互；超长省略号截断

### 按钮两态联动
- 右上三键（搜索/固定/菜单）随 header 两态缩放：静止 20×20（圆角 5）/ 悬停恢复 24×24（圆角 6）
- 图标与倒计时数字同步缩放；倒计时环 viewBox 自适应，进度语义不变

### 窗口两段式透明度
- **固定模式开启** → 窗口整体透明度降为 **60%**（实机调参定案，初版 80%）
- **贴边倒计时**（鼠标离开）→ 从不透明随剩余时间**线性降至 40% 可透视档**，
  倒计时结束达到「不影响观察下方窗口内容」；鼠标重进立即恢复
- 实现为主进程推送 + 渲染层 CSS alpha（`--win-alpha` 变量）——支持**悬停条目恢复 100%**
  （半透明状态下悬停的条目以完全不透明绘制，保证可读性；详见架构说明）
- 透明度计算纯函数化（`computeOpacity`），常量集中可调

## 🐛 问题修复

### 贴边抽屉动画失效（根治）
- 症状：面板贴边收起后复制内容，贴边触发条的抽屉动画不再播放
- 根因：v1.0.4 为修弹出闪烁引入 `backgroundThrottling: false`，其副作用是
  `document.visibilityState` 恒为 `'visible'`（窗口隐藏也不再变化）——贴边动画的
  gate 依赖 `visibilityState === 'hidden'` 判定贴边态，从此永不进入，动画播进了隐藏窗口
- 修复：可见性源迁移——主进程 `isWindowVisible` 为唯一权威（`setOnVisibilityChanged`
  回调 + `window:visibility` 频道），渲染层贴边 gate 与「重显动作」（筛选重置/搜索态
  恢复/贴边补播）全部迁移到权威信号
- 取证方式：userData 落盘诊断日志（五站埋点），复现一次即锁定「数据源到达、gate 零放行」

### FLIP 影子动画（测试工程师审计发现）
- 现象：展开动画 Invert 写入后、补间 rAF 未执行时窗口滑出（snap）——未决回调仍会
  起播一段「影子动画」，列表残留位移
- 修复：Play 代际令牌（`playGen`）——snap/新一轮 FLIP 作废未决回调；原 todo 用例
  转为真实断言（drain 后无影子起播）

### 拖拽结束无恢复缓冲（对齐设计稿）
- 拖拽结束瞬间光标通常仍压在 header 上，立即恢复 hover 判定会与「弹出即抖动」同构
- 修复：拖拽结束 200ms 恢复缓冲（`HEADER_DRAG_RESUME_MS` 常量，轮询判定带门禁）

### Header 缩减档同步
- 全部尺寸相关静态断言与结构测试同步至新基线（32/60、24×24 两态、钳制 36）

## ⚠️ 已知事项 / 行为变化

- **透明度为渲染层 CSS alpha**：header 渐变、搜索框、底部提示条**不随窗口透明度变化**
  （保持全不透明）——半透明时仅列表区域透视；如需 header 同步降透明度需另行调整
- 贴边触发条高度随静止 header 调整为 32px（钳制上限 36）
- 升级链路无签名/哈希校验（同 v1.0.4）；下载不支持断点续传
