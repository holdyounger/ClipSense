# ClipSense v1.0.2 Release Note

发布日期：2026-09-03

本版本聚焦**历史列表的浏览与检索体验**：日期分组、时间显示、返回顶部、按日期搜索，同时将全局快捷键调整为 `Alt+V`。

## ⌨️ 快捷键变更

### 全局快捷键：`Ctrl+Shift+V` → `Alt+V`
- 唤出/隐藏面板的全局快捷键改为 `Alt+V`（V 保留 clipboard 语义）
- 同步更新界面提示文案（中/英）与 README
- 历史发布文档（Release-v1.0.x）保持当时版本记录不动
- 修饰键防污染逻辑（`_waitForModifiersReleased`）原本就监控 Alt，无需功能改动

## ✨ 新特性

### 日期分组线
- 历史列表相邻条目自然日变化处插入「两侧横线 + 居中标签」分组线
- 标签规则：`今天` / `昨天` / 本年 `MM-DD` / 跨年 `YYYY-MM-DD`（杜绝年份歧义）
- 脏数据防御：timestamp 缺失或无效的条目不参与分组，条目本身仍正常渲染
- 搜索过滤后基于实际显示条目计算分组，不出现空组

### 入库时间显示优化
- 今天的条目仅显示 `HH:MM:SS`；非今天的条目显示 `MM-DD HH:MM:SS`
  （解决「昨天 10 点和今天 10 点看着没区别」的问题）
- 鼠标悬停条目 meta 行显示完整本地时间戳

### 返回顶部按钮
- 历史列表滚动超过 `120px` 后，右下角浮出圆形按钮，点击平滑滚回顶部
- 按钮位于 `#list` 外层（列表 innerHTML 全量重建不会吞掉按钮与滚动监听）
- 隐藏态用 `visibility+opacity` 切换，不拦截下方条目点击；贴边触发条模式下随面板隐藏

### 按日期搜索
- `date:` 前缀语法：`date:今天` / `date:昨天`（含 today/yesterday）、`date:09-02`、`date:2026-09-02`、`date:2026`（按年）
- 日期后可组合文本/时间：`date:昨天 评审`（日期+内容过滤）、`date:今天 10:30`（内容未命中时附带匹配入库时间串，实现按时间定位条目）
- 无前缀纯日期串（`09-02` / `2026-09-02`）自动识别为日期过滤
- 规则约定：`date:` 后第一个词必须是日期，否则显示空结果（不做文本 fallback）；「今天/昨天」两词与内容搜索冲突大，必须带 `date:` 前缀
- 日期解析容错不补零（`9-2` 等价 `09-02`）

## 🐛 问题修复

### 日期分组线导致渲染链中断（严重）
- `buildDateDivider` 中一个 span 的 class 值编辑失误，`querySelector` 返回 null 抛 TypeError
- 症状隐蔽：**主进程日志一切正常**（存储恢复成功），但渲染层顶层抛错使 `refresh()` 静默中断，UI 永远停留在初始「暂无剪贴板历史」
- 修复 class 值；引入 DOM 桩 harness 测试（node + 最小 DOM stub 直接调 `renderHistory`，覆盖文本/图片/文件/链接/空白字符/坏时间戳等形态）验证渲染链

## 🔧 内部改进

- `pad2` 提取为模块级工具函数（`timeStr` 与日期搜索共用）
- 日期搜索新增 `parseDateQuery` / `itemDayKey`，与分组线共用自然日 key 语义
- 搜索框 placeholder 更新为「搜索 内容或日期（date:昨天）...」提示新语法
