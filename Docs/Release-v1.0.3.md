# ClipSense v1.0.3 Release Note

发布日期：2026-09-16

本版本聚焦**搜索与标签体系融合、新条目「真抽屉」入场动画**，并修复固定/解锁倒计时失效、搜索交互后双击粘贴焦点回归、贴边触发条位置漂移等多个实机问题。测试基线 294 → 383 条，全量绿。

## ✨ 新特性

### 标签搜索（#tag 语法 + 标签内容匹配）
- 搜索框支持按标签检索：`#验证码`、`#链接`（标签显示名 / tag id 双轨，忽略大小写）
- 多 `#tag` 交集：`#链接 #邮箱` 同时命中两类（与筛选条 chip 语义一致，可叠加为三层交集）
- 与既有语法自由组合：`#验证码 date:昨天`（标签 ∩ 日期 ∩ 剩余词），两前缀互不吞噬
- 标签内容匹配：无 `#` 前缀的普通查询，除命中内容外同时命中标签显示名
  （搜「验证码」能出 otp 标签条目，即使正文不含该词）
- 未知 `#词` 返回空结果（对齐 `date:` 非日期语义，不做静默 fallback）

### 搜索体验增强（header 改造）
- 搜索框上移 header：点击图标展开（输入框占满 header 中部），再点 / Esc / 点击 header 外收起
- 收起即清词四路径统一：任何收起路径一律清词并恢复未过滤列表，杜绝隐形过滤
- Esc 一次完成「清词 + 收起 + 恢复自动隐藏」；IME 组合中（isComposing）忽略，不误收起
- 面板任意点击可启用键盘焦点：唤出后直接按 Ctrl+F 或点击列表即可输入

### 新条目入场动画（方案 B · spring 物理「真抽屉」）
- 主窗口态：新条目自 -24px、初速 -300px/s 弹入落位（一次自然过冲回弹），scale 0.94→1，
  opacity 前 120ms 淡入；WAAPI 合成器线程驱动，仅写 transform/opacity，结束即释放不驻合成层
- 贴边态（真抽屉三段式）：横向拉出 18px 露出柜内亮光 → 光珠坠入被吞 → 弹簧推回关上（≈650ms）；
  关键帧由主进程 `trigger-anim.js` 预积分，注入触发条回放
- 触发判定：仅「真新增」（条目 id 变化且 timestamp 距 now < 10s）播放入场；
  粘贴 rebase、历史装载、普通刷新、首次基线一律不播
- 贴边态新内容提醒：触发条 180ms 一次性脉冲（同一条目去重）+ 待播标记；展开面板后补播一次，
  未命中时由渲染 tick 兜底补播
- 系统开启「减弱动效」（prefers-reduced-motion）时跳过动画直接落位

## 🐛 问题修复

### 贴边触发条位置漂移 / 逐周期缩小直至消失
- 症状：每次复制后贴边条位置改变；频繁复制后条体逐渐缩小直至从屏幕消失
- 根因：抽屉动画「临时扩窗 → 回缩」编排以**每次事件现抓的窗口 bounds** 作为回缩基准；
  Windows DPI 取整使每轮 setBounds 产生 DIP↔物理像素舍入误差，快照回缩链将其**逐轮前馈累积**——
  连续复制时扩宽态被锁定回缩（每次向屏内漂 18px），或宽度逐周期缩小直至消失
- 修复（屏缘锚定，零快照）：静止位永远由 workArea 屏缘现算（x 锚定边缘、宽恒 6px、
  y/h 保留 header 实测），扩展位 = 静止位 ± travel，回缩时按「当前 bounds 所在屏幕」火线重算。
  每轮动画收敛到同一正确几何，漂移 / 缩小 / 走屏在结构上不再可能
- 保留守卫：动画周期内面板被唤出或触发条换边 → 跳过回缩，交由边缘检测全权接管

### 固定→解锁后倒计时失效
- 根因：`focus-search` IPC 末尾无条件挂起自动隐藏，叠加「面板任意点击启用键盘焦点」后，
  点击固定按钮即误闩「搜索中」标志，自动隐藏倒计时被永久卡住
- 修复：挂起仅由搜索框真实 focus 事件触发；解锁（取消固定）时主动清除一次挂起标志

### 搜索交互后双击粘贴焦点回归
- 根因：面板可聚焦后，搜索/点击交互使双击时前台已是面板自身（抓取被自身过滤规则拦下），
  回退的目标句柄陈旧或为空 → 粘贴焦点留在面板
- 修复：`FocusTracker` 新增 `refresh()`（抓到 0 不清空旧记录）；`focus-search` 在抢焦**前**
  同步刷新粘贴目标——抢焦前前台仍是真实目标窗口，交互后目标句柄保持新鲜

### 其他
- 搜索展开态头部不再被拖拽热区吞掉点击（`.header-search` no-drag）
- 搜索收起时任意按键误触发清词收起的问题（Esc 按键检查）
- 连续双击粘贴「只有第一条成功」：粘贴后抑制轮询归档 + 重建基线，防 DOM 被销毁吞事件
